# Islam Magdi - UI/UX Designer Portfolio

A modern, responsive portfolio website showcasing UI/UX design work with glassmorphism effects, smooth animations, and contemporary design trends.

## 🌟 Features

- **Modern Design**: Dark theme with purple gradients and glassmorphism effects
- **Responsive Layout**: Optimized for desktop, tablet, and mobile devices
- **Smooth Animations**: Built with Motion (Framer Motion) for fluid interactions
- **Performance Optimized**: Fast loading with modern web technologies
- **SEO Friendly**: Proper meta tags and structured content

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ installed on your system
- Git for version control

### Local Development

1. **Clone the repository**
   \`\`\`bash
   git clone https://github.com/islammagdi/UIX-Profile.git
   cd UIX-Profile
   \`\`\`

2. **Install dependencies**
   \`\`\`bash
   npm install
   \`\`\`

3. **Start development server**
   \`\`\`bash
   npm run dev
   \`\`\`

4. **Open your browser**
   Navigate to \`http://localhost:3000\`

### Build for Production

\`\`\`bash
npm run build
\`\`\`

### Preview Production Build

\`\`\`bash
npm run preview
\`\`\`

## 🌐 Deploy to GitHub Pages

### Method 1: Automatic Deployment (Recommended)

1. **Push to GitHub**
   \`\`\`bash
   git add .
   git commit -m "Initial commit"
   git push origin main
   \`\`\`

2. **Enable GitHub Pages**
   - Go to your repository settings
   - Navigate to "Pages" section
   - Select "GitHub Actions" as source
   - The workflow will automatically deploy on every push to main

### Method 2: Manual Deployment

1. **Build and deploy**
   \`\`\`bash
   npm run build
   npm run deploy
   \`\`\`

## ⚙️ Configuration

### Update Repository URLs

Before deploying, update the following files with your GitHub username and repository name:

1. **package.json**
   \`\`\`json
   "homepage": "https://[your-username].github.io/[repository-name]"
   \`\`\`

2. **index.html**
   - Update the Open Graph URLs
   - Update Twitter card URLs

### Custom Domain (Optional)

To use a custom domain:

1. Add a \`CNAME\` file in the \`public\` directory
2. Add your domain name to the file
3. Configure DNS settings with your domain provider
